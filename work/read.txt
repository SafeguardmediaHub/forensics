🎥 VIDEO FORENSICS – What Happens in Background

Let’s break this down simply.

When you upload a video, the system:

1️⃣ Extracts Frames

A video is just thousands of images played quickly.

The system:

Breaks video into frames

Stores them temporarily

Now it analyzes those frames.

2️⃣ Compares Frames to Each Other

It looks for:

Sudden changes

Duplicate frames

Blurring artifacts

Compression inconsistencies

Structural similarity issues

It uses things like:

SSIM (Structural Similarity Index)
Measures how similar two frames are.

Perceptual Hash (pHash)
Detects duplicate or reused frames.

Optical flow
Detects unnatural motion patterns.

What This Detects
Manipulation	How It Shows Up

Scene insertion	Scene detection spike
3️⃣ Scene Detection

The system finds:

4️⃣ Aggregates Results

Instead of saying:

🎧 AUDIO FORENSICS – What Happens in Background

Audio analysis is more complex than video.

When you upload audio:

1️⃣ Chain of Custody

The system:

Hashes file (SHA-256)

Stores original safely

Logs all actions

Why?

Because in real forensic environments:

You must prove the file wasn’t altered during analysis.

2️⃣ Integrity Analysis

It checks for:

Sudden waveform discontinuities

Spectral anomalies

Bit-depth inconsistencies

Clipping artifacts

These indicate:

Cuts

Overdubbing

Editing

Recompression

3️⃣ Speaker Analysis

Extracts:

Pitch patterns

Formants

MFCC features

Then compares to:

Reference speaker

Or checks internal consistency

This detects:

Voice impersonation

Spliced speakers

Synthetic voice artifacts

4️⃣ ENF Analysis (Very Powerful)

ENF = Electrical Network Frequency.

Background electrical hum in recordings follows a real-world grid frequency pattern (50Hz or 60Hz).

If someone edits audio:

The ENF pattern breaks

Continuity is lost

This can:

Detect tampering

Verify timestamp claims

This is used in real-world investigations.

5️⃣ Event Detection

It detects:

Gunshots

Vehicles

Environmental sounds

This helps:

Timeline reconstruction

Context verification

6️⃣ Statistical Confidence

All results are combined into:

A final confidence score

With weighted components
